2. DETAILED BREAKDOWN BY PLATFORM
--------------------------------------------------------------------------------

================================================================================
A. GITHUB CODESPACES (FREE TIER)
================================================================================
1. Monthly Allowance:
   - Compute: 120 core-hours per month (resets on 1st of each calendar month).
     * 2-core machine (8 GB RAM): 60 hours of active development time.
     * 4-core machine (16 GB RAM): 30 hours of active development time.
   - Storage: 15 GB-months of persistent disk allocation.
   - Spending Limit: Set to $0.00 USD by default (prevents any accidental charges).

2. Architectural Highlights:
   - Full Linux Virtual Machine: Full root/sudo permissions. You can install system
     packages (apt-get), run Docker-in-Docker, run long-lived daemons, and host web
     servers.
   - Native SSH Access: Connect directly from Windows Terminal via 'gh cs ssh'.
   - Custom Environment: Define any container base, features, and startup scripts
     in .devcontainer/devcontainer.json.
   - Port Forwarding: Forward cloud ports directly to localhost:8000 on Windows.

3. Optimization Strategy for Free Tier:
   - Always provision with 2-core machines (standardLinux32gb).
   - Set idle timeout to 15m (gh cs create --idle-timeout 15m).
   - Storage Hygiene: Delete codespaces (gh cs delete -c <name> --confirm) after
     pushing code to GitHub, to prevent storage quota exhaustion.

================================================================================
B. GOOGLE COLAB (FREE TIER)
================================================================================
1. Monthly Allowance & Quota:
   - Compute Quota: Dynamic allocation based on demand. Google does not publish a
     fixed hour number; users typically receive ~15-25 hours of active GPU compute
     per week before rate limiting triggers.
   - Reset Cycle: Daily dynamic replenishment.

2. Hardware Capabilities:
   - CPU: ~2 vCPUs, ~12.7 GB System RAM.
   - GPU: 1x Nvidia Tesla T4 GPU (15 GB VRAM) for accelerated deep learning.
   - TPU: TPU v2-8 (optional hardware acceleration).
   - Storage: ~100 GB ephemeral disk (wiped when runtime disconnects). Can mount
     personal Google Drive (15 GB free standard Google storage).

3. Strengths & Limitations:
   - Strengths: Zero setup for PyTorch, TensorFlow, and HuggingFace; free GPU/TPU
     access; easy sharing of interactive `.ipynb` notebook links.
   - Limitations: No direct OpenSSH connection (interactive web only); non-persistent
     disk; disconnects after 90 minutes of inactivity or 12 hours total runtime.

4. Optimization Strategy:
   - Switch hardware accelerator to 'None' (CPU) when writing/debugging code; enable
     GPU only during model training loops.
   - Mount Google Drive (drive.mount('/content/drive')) to save model weights and
     datasets before the VM terminates.

================================================================================
C. KAGGLE CLOUD RUNNER (FREE TIER)
================================================================================
1. Weekly Allowance:
   - GPU Compute: 30 hours of FREE GPU per week (resets every Saturday/Sunday).
   - TPU Compute: 20 hours of FREE TPU v3-8 per week.
   - CPU Compute: Unlimited sessions (within concurrency caps, up to 10 simultaneous).

2. Hardware Capabilities:
   - CPU Mode: 4 vCPUs, 30 GB System RAM.
   - GPU Mode: 2x Nvidia Tesla T4 GPUs (or 1x Nvidia Tesla P100 16GB VRAM).
   - TPU Mode: TPU v3-8 (128 GB memory total).
   - Storage: 20 GB persistent working directory output + 73 GB temporary scratch disk.

3. Strengths & Limitations:
   - Strengths: Most generous guaranteed free GPU hours (30 hrs/week); massive dataset
     library pre-mounted (no download time); supports background "Save & Run" batch
     execution up to 12 hours without keeping a browser open.
   - Limitations: Outbound internet requires one-time SMS phone verification;
     interactive session idle timeout is 40 minutes.

4. Optimization Strategy:
   - Use CPU mode for data preprocessing and exploration (saves your 30 GPU hours).
   - Use background Commit & Run batch jobs so you don't consume interactive idle time.
   - Use the Kaggle CLI ('kaggle kernels push') to run headless scripts from Windows.


--------------------------------------------------------------------------------
3. COMPARATIVE SELECTION GUIDE: WHICH FREE RUNNER SHOULD YOU USE?
--------------------------------------------------------------------------------

1. CHOOSE GITHUB CODESPACES IF:
   - You need a true Linux terminal / development environment.
   - You use screen readers (NVDA / JAWS) and want distraction-free SSH.
   - You are building software projects, web services, APIs, or CLI tools.
   - You want seamless Git synchronization with your GitHub repositories.

2. CHOOSE GOOGLE COLAB IF:
   - You want quick interactive data exploration or tutorial notebooks (.ipynb).
   - You need rapid access to an Nvidia T4 GPU for testing deep learning models.
   - You want to collaborate or share executable Python experiments via web links.

3. CHOOSE KAGGLE CLOUD RUNNER IF:
   - You need high RAM (30 GB) or multi-GPU (2x T4) / TPU compute for heavy training.
   - You want guaranteed 30 hours/week GPU quotas that do not fluctuate dynamically.
   - You want to launch long-running 12-hour background training jobs without keeping
     your laptop on.
