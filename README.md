# Accessible GitHub Codespaces via Terminal & CLI

An open-source reference project and curriculum demonstrating how screen reader users and terminal-first developers can provision, configure, develop, and manage cloud workspaces on **GitHub Codespaces** strictly using the command line (`gh`, `git`, and OpenSSH) on Windows 11.

---

## Overview

Traditional cloud development environments rely heavily on complex browser-based web editors (such as VS Code for Web), which can introduce accessibility challenges, focus traps, or screen reader lag. 

This repository provides:
1. **A Headless Cloud Spec (`.devcontainer/devcontainer.json`)**: Pre-configured Debian container with OpenSSH, Python 3.12+, and plain shell prompts (avoiding unannounced ANSI colors or private-use Unicode symbols).
2. **A Sample Python Application**: A CSV data analysis and missing value imputation tool (`src/data_analyzer.py` and `src/cli.py`) with unit tests.
3. **Comprehensive Screen Reader Guide (`TUTORIAL.md`)**: A WCAG 2.1 AA compliant step-by-step curriculum for NVDA and JAWS users to manage Codespaces via the GitHub CLI (`gh`).

---

## Quick Start (Local Machine)

### 1. Run Analysis on the Sample Dataset
```powershell
python -m src.cli -i data/sample_data.csv -o data/cleaned_data.csv -s auto
```

### 2. Run Automated Unit Tests
```powershell
python -m unittest discover -s tests -p "test_*.py" -v
```
